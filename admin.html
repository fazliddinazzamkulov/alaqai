Добро пожаловать

Эта панель управляет ключами ИИ/фотобанков, подписками учителей и (для руководителя) безопасностью аккаунтов. Ничего из этого не видно и не доступно обычным учителям.

Хранилище ключей API

Ключи шифруются на сервере (AES-256-GCM) и никогда не попадают в браузер учителя. Для Gemini можно указать до 3 ключей — при перегрузке одного сервер автоматически переключится на следующий.
