# Провайдеры для подключения — короткий список

Интерфейс входа, оплаты, кабинета и админки готов. Чтобы он заработал по-настоящему, нужно выбрать сервисы и
передать мне ключи (я положу их только в переменные окружения сервера, в код они не попадают).

Цены ориентировочные (по открытым тарифам 2025–2026), перед подключением сверьте их на сайте провайдера.
«★» — то, что вы уже выбирали раньше; я рекомендую оставить этот выбор.

## 1. Вход через Google

| Вариант | Цена | Что нужно от вас |
|---|---|---|
| ★ Google Identity Services (уже встроено в сервер) | бесплатно | OAuth Client ID из Google Cloud Console (тип «Web»), домены `alaqai.online` и `api.alaqai.online` в списке разрешённых |

## 2. SMS с кодом для входа

| Вариант | Цена за SMS в Казахстане | Плюсы / минусы |
|---|---|---|
| ★ Mobizon.kz | ~12–17 ₸ | Казахстанский сервис, простой API, оплата в тенге. Нужна регистрация имени отправителя (1–3 дня) |
| SMSC.kz | ~12–16 ₸ | Похож на Mobizon, давно на рынке |
| Telegram Gateway | ~0,01 $ (~5 ₸) за код | Очень дёшево, но код приходит в Telegram, а не SMS — подходит не всем учителям |
| Twilio Verify | ~0,25–0,35 $ (~130–180 ₸) | Надёжно, но в 10 раз дороже местных |

Нужно от вас: API-ключ и одобренное имя отправителя (например, `alaqai`).

## 3. Kaspi QR

| Вариант | Комиссия | Комментарий |
|---|---|---|
| ★ Kaspi Pay напрямую (Kaspi Business) | ~0,95–2 % | Самый дешёвый, но API для сайтов дают не всем — нужна заявка в Kaspi Business |
| Через агрегатор (FreedomPay, ioka и др.) | ~2–3,5 % | Один договор сразу на Kaspi и карты, подключение быстрее |

Нужно от вас: договор / доступ к API Kaspi (или договор с агрегатором) и реквизиты ИП/ТОО.

## 4. Платёжный шлюз: карты, Apple Pay, Google Pay, автопродление

| Вариант | Комиссия | Комментарий |
|---|---|---|
| ★ CloudPayments (Казахстан) | ~2,5–3,5 % | Готовый виджет, рекуррентные платежи (автопродление), Apple Pay и Google Pay |
| FreedomPay (ex-Paybox) | ~2,5–3,5 % | Есть Kaspi в том же договоре |
| Halyk ePay | ~2–3 % | Банковский шлюз, подключение дольше |

Stripe и PayPal для казахстанского ИП/ТОО недоступны. Нужно от вас: Public ID и API secret шлюза, договор.

## 5. База данных и хостинг

| Вариант | Цена | Комментарий |
|---|---|---|
| ★ VPS в Казахстане + SQLite (сервер уже написан под SQLite) | ~3 000–6 000 ₸/мес (PS.kz, Hoster.kz и др., 2 vCPU / 2–4 ГБ) | Персональные данные хранятся в РК, как требует закон о персональных данных. Ежедневная копия базы — отдельно, ~500–1 000 ₸/мес |
| VPS в РК + PostgreSQL | те же ~3 000–6 000 ₸/мес | Нужен, если учителей станет много (десятки тысяч) — переход с SQLite можно сделать позже |
| Облачная база за рубежом (Supabase, Neon) | 0–25 $/мес | Удобно, но данные учеников вне Казахстана — не рекомендую |

Нужно от вас: VPS в Казахстане (Ubuntu 22.04/24.04) и домен `api.alaqai.online`. Сервер — репозиторий `alaqai.back`, установка одной командой `deploy/setup.sh` (см. его README).

## Итого при рекомендованном выборе

- Постоянно: ~4 000–7 000 ₸/мес (VPS + резервные копии).
- За использование: ~12–17 ₸ за каждый вход по SMS; ~1–3,5 % с каждой оплаты.
- Google-вход и сам код — без платы.
