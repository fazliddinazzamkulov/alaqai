# alaqai v2 — генератор урока, урок с учениками, рост учеников

Дата: 19.11.2026. Утверждено Фазлиддином в чате («да начнем»).
Макеты: https://claude.ai/artifact/H5sLSfQ9AaJ9nUwwWSMv37 (8 экранов).

## Зачем

Главное — ученики и их рост. Учитель работает с каждым учеником
индивидуально, но одновременно: каждый получает задание своего уровня (A, B, C)
и сам выбирает удобный способ (методику). Платформа запоминает, после какой методики
ученик решает лучше, и показывает учителю, кто отстаёт. Нужна и для выступления
на «Педагогикалық идеялар фестивалі» (27.11.2026).

Учителю должно быть легко: мало кнопок, крупный текст, понятные цвета.

## Цели

1. Генератор: одна тема → презентация из 50 шаблонов + КСП на весь урок (Word).
2. Урок с учениками: вход по коду на alaqai.online (как ClassPoint), задания по
   уровням, выбор методики учеником, «нужна помощь», экраны учеников идут за
   слайдом учителя, рейтинг (топ‑5 на доску или каждому его место), задание
   онлайн или в тетради (учитель ставит оценку сам), перерыв от экрана.
3. Рост: по каждому ученику — график итоговых проверок, какая методика помогает,
   рекомендация ИИ (решает учитель), список отстающих.

## Не делаем сейчас (добавим позже)

Игры и викторины как отдельный раздел, календарь, подписка и оплата в меню,
отдельный раздел ДЗ, тесты как раздел, мобильное приложение, запуск Python в браузере.
Код этих экранов не удаляем — просто убираем из меню.

## Анти-цели

- ИИ не решает за учителя: перевод на уровень и выводы — только по кнопке учителя.
- КСП не должен состоять только из платформы: это план всего урока.
- Не больше 25 минут за компьютером (8 класс; 9–11 — 30), подряд не больше 15–20.
- Ключи API никогда не попадают в браузер.

## Ограничения

- Фронтенд — статический, ES-модули без сборки (GitHub Pages и nginx отдают как есть).
- Бэкенд — существующий alaqai.back (Express + node:sqlite, один процесс).
- Домены: alaqai.com — учитель, alaqai.online — ученик. Пока сайт на GitHub Pages
  (CNAME alaqai.online), учительская часть живёт по адресу /app/, ученическая — /join/.
  Когда сервер запущен, nginx отдаёт те же файлы: alaqai.com → /app/, alaqai.online → /join/.
- Срок: к 20.11 — этап 1 (генератор + КСП + код-шаблоны); этап 2 сразу после.
- Урок 40 минут. Санитарные правила РК: непрерывная работа с компьютером
  4–8 кл. ≤ 25 мин, 9–11 кл. ≤ 30 мин.

## Подходы, которые рассматривали

1. **Перекрасить старое приложение /app.** Быстро, но старый дизайн и 12 макетов
   слайдов остаются внутри, меню перегружено. Отклонено: Фазлиддин попросил
   «всё с начала».
2. **Новое приложение /app на модулях старого (выбран).** Новый интерфейс по
   макетам, а проверенные части (данные и синхронизация, вход, ИИ-клиент,
   экспорт КСП в Word) переносятся. Слайды — движок из 50 шаблонов
   (alaqai-slides.html) во фрейме, связь через postMessage.
3. **Отдельный сервис для урока (WebSocket).** Мгновенно, но ещё один сервер.
   Отклонено: опрос раз в 2 секунды через alaqai.back достаточно для класса из 30.

## Как устроено (решено)

### Учитель (/app, макеты 1–6)
- Меню: Главная, Мои уроки, Провести урок, Рост учеников, Классы. Синяя кнопка
  «Создать урок». Язык по умолчанию — қазақша (ҚАЗ/РУС/ENG).
- Создать урок: тема, класс, предмет, язык урока, материал (фото/PDF/Word),
  набор шаблонов (подобран по предмету), 8/10/12 слайдов, картинки
  (Pexels/Pixabay, ИИ Nano Banana, без картинок).
- Урок хранится набором: презентация (deck JSON движка), КСП, задания по уровням.
- Презентация: миниатюры слева, слайд по центру, справа — сменить шаблон,
  попросить ИИ, картинка.
- КСП: форма Казахстана, весь урок по этапам, «Әдіс-тәсілдер», таблица
  «Саралау / Бағалау / Денсаулық және қауіпсіздік», «Скачать Word».

### Слайды
- Движок: 50 шаблонов из alaqai-slides.html, данные — JSON.
- Новые шаблоны для кода: `predict` (что выведет программа), `codefill`
  (допиши код), `parsons` (собери код из строк), `error` с `code: true`
  (найди ошибку в коде, моноширинный шрифт), `steps` (пошагово: вопросы с полями).
- Каждый шаблон-задание сообщает результат (`report`: шаблон, верно, всего) —
  это основа статистики «какая методика помогает».

### Урок с учениками (макеты 5, 7, 8)
- Учитель жмёт «Провести урок» → сервер создаёт урок с кодом из 6 цифр.
- Ученик на alaqai.online/join: код → своё имя из списка класса → вход.
  Устройство запоминает ученика (токен в localStorage).
- Индивидуальный блок: для каждого уровня A/B/C — три методики:
  «Пошагово» (`steps`), «Разбор примера» (`example` + `input`), «Найди ошибку» (`error`).
  Ученик выбирает методику; после 3+ уроков платформа подсказывает лучшую.
- Общее задание: одно для всех.
- Режим «В тетради»: ученик видит задание, учитель ставит оценку на своём экране.
- Перерыв: «Перерыв 5 мин» закрывает экраны учеников заданием для тетради и
  гимнастикой для глаз. У учителя счётчик «за компьютером N из 25 мин».
- Рейтинг: «Топ‑5 на доску» или «Каждому его место».
- «Нужна помощь» у ученика → карточка учителя становится оранжевой.
- Опрос раз в 2 с; состояние урока — в памяти сервера, результаты пишутся записями
  `attempts` учителя (синхронизация уже есть).

### Рост (макет 6)
- Из `attempts`: итоговая проверка по урокам, % верных по методикам,
  отстающие (3 урока ниже 50%, пропуски, «нужна помощь» без решения).
- Рекомендация ИИ — текст с кнопками «Перевести на …» / «Оставить».

### План урока информатики (для генератора КСП и подсказок)
0–3 начало (без ПК) · 3–10 объяснение по презентации (без ПК) · 10–17 задания
по уровням на alaqai (ПК 7 мин) · 17–22 перерыв от экрана: задание в тетради/в паре ·
22–37 практика в Python (ПК 15 мин) · 37–40 рейтинг, рефлексия, ДЗ (без ПК).
За компьютером 22 мин.

## Оставлено исполнителю

Внутренние имена модулей, разметка, порядок экранов в коде, тексты подсказок,
формат JSON КСП (совместимый с ksp/doc.js), ограничения запросов на сервере.
