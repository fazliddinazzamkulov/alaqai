# alaqai v2 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** New teacher app (generator: presentation from the 50-template engine + full-lesson KSP), live lesson with students by code, and student growth.

**Architecture:** Static ES-module frontend without a build step. `app/` (teacher) is rewritten to the new design and reuses proven modules from the old app (moved to `legacy/app-v1/`). Slides run in `app/slides/player.html` (the 50-template engine) inside an iframe, driven by postMessage. Live lessons are a new `/api/live` router in `alaqai.back` (in-memory session, 2 s polling, results saved as `attempts` records). Students use `join/`.

**Tech Stack:** Vanilla JS modules, Gemini via `/api/ai/*`, Express + node:sqlite, `node --test`, Playwright (Python) for screenshots.

**Spec:** `docs/superpowers/specs/2026-11-19-alaqai-v2-design.md`

## Global Constraints

- UI languages ҚАЗ/РУС/ENG, default `kk`. Lesson languages kk, ru, en, uz.
- Design tokens (from the 50 templates): ink `#0B0B0C`, accent `#2563EB`, accent-soft `#EAF1FF`, bg `#F4F4F0`, paper `#FFFFFF`, line `#E3E3DD`, ok `#17803D`, warn text `#8A4B00`, bad `#B42318`; fonts TikTok Sans (headings), Inter (body), JetBrains Mono (code), Poppins (logo). No gradients, no emoji, line icons. Touch targets ≥ 44 px.
- Levels: A — базовый (green `#17803D`), B — средний (blue `#2563EB`), C — высокий (ink).
- Methods (student chooses): `steps` «Пошагово», `example` «Разбор примера», `error` «Найди ошибку».
- Screen time: grades 4–8 ≤ 25 min per lesson, 9–11 ≤ 30 min; break button default 5 min.
- API keys never reach the browser. API base `window.ALAQAI_API_BASE` (default `https://api.alaqai.online`).
- Removed from the menu (code kept): games, tests, homework section, calendar, subscription, guide.

## Review Focus

1. AI returns a slide with an unknown `type` or missing fields → the slide is fixed or dropped, the deck still opens (Task 2 test `drops unknown types`).
2. Student opens the join page with a wrong or finished code → clear message, no crash (Task 9 test `404 for unknown code`; Task 10 shows the message).
3. Two devices pick the same student name → second gets “уже вошёл” (Task 9 test `same student twice`).
4. Teacher closes the tab mid-lesson → students keep the last state; reopening the lesson screen resumes the same code (Task 9 test `teacher resume`).
5. KSP minutes do not add up to 40 or screen time exceeds the limit → normalizer rescales and flags it (Task 3 test `ksp minutes sum to 40`).
