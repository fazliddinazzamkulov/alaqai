# alaqai — ход работ по платформе

Дизайн: холст «alaqai — платформа», экраны 1–32 (https://claude.ai/artifact/MKNcHn6V5hep5THNZ9zD7x).
Ветка: `claude/platform`. Если чат закончится — продолжать с первого пункта без галочки.

## Архитектура (почему так)

Платформа — статическое одностраничное приложение в папке `/app` на обычных ES-модулях без сборки: GitHub Pages
отдаёт его как есть, ничего не нужно устанавливать и собирать, а каждый экран — отдельный файл в `app/js/views/`,
который подгружается только когда его открыли (роутер на `#/адресах` в `app/js/main.js`). Все данные идут только
через слой `app/js/data/store.js` с асинхронными методами `list / get / create / update / remove`: сейчас он хранит
данные в браузере (localStorage), а когда будет выбрана база, пишется HTTP-адаптер к серверу `server/` и
подключается одной строкой `useAdapter(...)` — экраны не меняются. Всё, что требует секретов (Gemini, картинки,
оплата, SMS), идёт через Node-сервер `server/`: ключ Gemini хранится только там (зашифрованным), браузер его не видит.
Тексты на трёх языках лежат рядом с каждым экраном (`add({ ru, kk, en })`), язык общий с лендингом (`alaqai_lang`).

Старая платформа перенесена в `/legacy` (удалить после проверки). `platform.html` в корне перенаправляет в `/app/`.

## Этапы

- [x] **1. Каркас** — меню (общий компонент), главная со статистикой (1), календарь (22), классы (5), переключатель языка ҚАЗ/РУС/ENG.
  - Слой данных, расчёт статистики (качество знаний, успеваемость, средний балл, посещаемость, динамика), школьный календарь (четверти, недели, звонки).
  - Пустые состояния + кнопка «Заполнить примером» (демо-классы с журналом за 8 недель, удаляется одной кнопкой).
  - Календарь: неделя / день / месяц, добавление урока в расписание, статусы «готов / проведён / не подготовлен».
  - Классы: создание, редактирование, список учеников (вставка списком), удаление.
  - Телефон: меню выезжает слева.
- [x] **2. «Создать урок» (2) и «Уроки» (3)** — одна тема → КСП, презентация, игры, викторина, тест, ДЗ; урок хранится набором, каждая часть — в своём разделе.
  - ИИ идёт через сервер (`app/js/ai.js` → `/api/ai/generate`); промпты — `app/js/gen/prompts.js`, сборка урока — `app/js/gen/lesson.js`.
  - Презентация, игры+викторина и тест+ДЗ создаются параллельно, КСП — последним со ссылками на слайды, игры и ДЗ.
  - Прогресс по частям, «Повторить» для части с ошибкой; если ИИ недоступен (не вошли, тариф, нет ключей, нет сети) — понятное сообщение и «Создать без ИИ».
  - Урок из календаря («+ Создать урок» в пустой ячейке) заполняет именно этот слот. Загрузка страниц учебника (фото/PDF) уходит в промпт.
  - «Уроки»: список с фильтром и карточка урока (6 частей, план урока из КСП, «Поставить в расписание», удаление набором).
- [x] **3. Презентации (6, 7)** — генерация, 5 языков, 16:9 и 4:3, ручной редактор, ИИ-агент.
  - Движок слайдов `app/js/slides.js` + `app/css/slides.css` (12 макетов, размеры в container units — один и тот же слайд в миниатюре, редакторе, на уроке и в PDF; формулы через KaTeX).
  - «Новая презентация»: тема, материал (PDF/фото — в Gemini, DOCX/PPTX — текстом через JSZip), 5 языков + «Другой…», 16:9/4:3, 6–12 слайдов, 5 цветовых тем, фото / иконки (Iconify) / AI-изображения / вопросы классу. «Мои презентации», пустая презентация.
  - Редактор: правка текста прямо на слайде (жирный, маркер), Enter — новый пункт; фото (поиск, своё, ИИ), иконка, формула, диаграмма, мини-игры, смена макета, порядок/копия/удаление слайдов, отмена (Ctrl+Z), автосохранение, «Скачать PDF» (печать браузера, слайд на страницу).
  - Агент справа: просьба своими словами → изменённые слайды с «Оставить / Вернуть как было»; быстрые кнопки (вопрос классу, перевод, сократить, другое фото).
  - Сервер: `/api/images/search` принимает `page`, чтобы «Другое фото» давало новую картинку.
- [x] **4. Тесты и игры (8, 9).**
  - Конструктор теста: «С ИИ» (материал PDF/DOCX/фото/текст, 5–20 вопросов, типы, сложность) или «Вручную»; правка каждого вопроса: тип (один ответ, несколько, правда/ложь, открытый, число), баллы, варианты с отметкой верного, картинка, пояснение, «✦ Улучшить» (ИИ переписывает вопрос), копия/удаление. Предпросмотр с автопроверкой и оценкой, «Дать как ДЗ», «Мои тесты».
  - Логика проверки и плеер теста — `app/js/testlogic.js` (пригодятся в режиме урока и онлайн-ДЗ).
  - Игры: 9 форматов из старого конструктора (`app/js/games.js`: викторина, совпадения, кроссворд, мемори, вставь слова, найди слова, правда/ложь, анаграмма, сортировка) в новом дизайне; «Чаще всего используете» сортируется по реальному использованию, 3 места «Новые игры · скоро», конструктор с живым предпросмотром и «✦ Заполнить с ИИ», «Мои игры», игры конкретного урока.
- [x] **5. Режим урока (13–19)** — панель внизу, журнал с посещаемостью, группы, колесо фортуны, барабан, шумомер с таймером и монстриком, загрузка PDF/PPTX/DOCX.
  - `app/js/views/lessonmode.js`: слайд на весь экран (16:9 и 4:3, для 4:3 — боковые колонки с файлом, таймером и тем, кто отвечает), тонкий док: материалы (презентация, игра, викторина, тест, ДЗ, свой файл), листание (стрелки, пробел, свайп), 8 инструментов, часы/таймер, «Завершить».
  - Журнал справа (баллы −/+, «+1 всем», посещаемость, «Все пришли»), группы (2–5, поровну по баллам «змейкой» или случайно, баллы группам, «Перемешать», «Колесо групп»); всё сохраняется в `marks` и `lesson.live`.
  - Выбор ученика (`lesson/picker.js`): яркое колесо фортуны, колесо групп → колесо учеников группы, барабан по группам, карточка; «Не повторять», отсутствующие не участвуют, «+1 балл» / «+1 балл группе».
  - Шумомер (`lesson/noise.js`): микрофон, добрый монстрик (спит → приоткрыл глаза → проснулся и просит потише), шарики, шкала, таймер тишины (идёт только пока тихо), ползунок для проверки без микрофона.
  - Свои файлы (`lesson/files.js`): PDF (pdf.js), PPTX (слайды через JSZip, размер 16:9/4:3 из файла), DOCX (mammoth), картинки.
  - Также: ИИ-чат по текущему слайду, таймер/секундомер, доска поверх слайда, затемнение (B), полный экран (F). «Завершить» сохраняет журнал и ставит урок «проведён».
- [ ] **6. КСП (4)** — Word по формату и ссылка «только просмотр».

## Что осталось / заметки

- Разделы этапов 3–8 пока открывают заглушку «Раздел скоро появится».
- Проверка генерации в браузере сделана с подменой ответа сервера (ключа Gemini в среде разработки нет); после входа через Google и добавления ключей в админке работает с настоящим ИИ.
- Статистика «ДЗ сдают вовремя» заработает на этапе 7 (пока «—»).
- Тариф в меню берётся из настроек (по умолчанию «Базовый»); реальный учёт лимитов — на сервере, этап 8.
