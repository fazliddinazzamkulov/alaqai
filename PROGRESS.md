# alaqai — ход работ по платформе

Дизайн: холст «alaqai — платформа», экраны 1–32 (https://claude.ai/artifact/MKNcHn6V5hep5THNZ9zD7x).
Ветка: `claude/platform`. Если чат закончится — продолжать с первого пункта без галочки.

## Архитектура (почему так)

Платформа — статическое одностраничное приложение в папке `/app` на обычных ES-модулях без сборки: GitHub Pages
отдаёт его как есть, ничего не нужно устанавливать и собирать, а каждый экран — отдельный файл в `app/js/views/`,
который подгружается только когда его открыли (роутер на `#/адресах` в `app/js/main.js`). Все данные идут только
через слой `app/js/data/store.js` с асинхронными методами `list / get / create / update / remove`: рабочая копия
хранится в браузере (localStorage), а у вошедшего учителя `app/js/data/sync.js` отправляет каждое изменение на сервер
и забирает изменения с других устройств. Всё, что требует секретов (Gemini, картинки, оплата, SMS), идёт через
сервер из отдельного приватного репозитория `alaqai.back`: ключи хранятся только там (зашифрованными), браузер их не видит.
Тексты на трёх языках лежат рядом с каждым экраном (`add({ ru, kk, en })`), язык общий с лендингом (`alaqai_lang`).

Старая платформа перенесена в `/legacy` (удалить после проверки). `platform.html` в корне перенаправляет в `/app/`.

  - Инструкция: 7 шагов, шаг отмечается сам, когда учитель сделал это на платформе (пример не считается), или вручную; место под видео (ссылку на видео по шагам добавит админ — YouTube или файл).
  - Пример («Заполнить примером») теперь включает ДЗ, сданные работы с фото и итоги урока с викториной.
- [x] **8. Вход (23–25), оплата (26–27), кабинет (28), админка /admin (29–32)** — интерфейс готов; подключение провайдеров — после выбора (см. `docs/providers.md`).
  - Вход `#/login`: Google (настоящий, через уже готовый `/api/auth/google`; нужен Client ID в `app/index.html`) и телефон → `#/login/code` (4 цифры, повторная отправка через 60 с). SMS-маршруты сервера (`/api/auth/sms/send|verify`) появятся с SMS-сервисом, до этого экран честно пишет «заработает после подключения».
  - `#/preview` — пример урока без входа: слайды листаются, части урока под замком, «Войти, чтобы провести».
  - Оплата `#/checkout?plan=&period=`: Стандарт/Max, 1 или 6 месяцев, промокод, итог; карта / Kaspi QR / Google Pay / Apple Pay. Данные карты страница не принимает сама — поля и кнопки неактивны, пока сервер не сообщит, что способ подключён (`/api/billing/config`); оплату будет запускать сервер через виджет шлюза.
  - Кабинет `#/account`: профиль (имя, школа, предметы, язык, фото), способы входа, тариф и лимит недели, история платежей, «Выйти», «Выйти на всех устройствах», «Удалить аккаунт» (у гостя — удаляет данные в браузере). Тариф берётся с сервера для вошедших.
  - Админка `/admin/` (отдельная страница, те же модули): вход только для admin/owner через Google; «Посмотреть на примере данных» — демо-режим с пометкой. Экраны: обзор (KPI, выручка по дням, тарифы, последние платежи, «требует внимания»), база данных (пользователи/уроки/подписки/платежи/школы, поиск, фильтры, CSV), аккаунт (данные, опасная зона, смена тарифа, ручное продление, блокировка, сброс сессий, журнал), подписки и тарифы (цены и лимиты редактируются, способы оплаты, промокоды, заявки школ), платежи, ИИ: ключи API (добавить/выключить/удалить ключ Gemini и др. — через старый защищённый сейф на сервере), администраторы (роли выдаёт владелец), журнал действий.
  - Уже работает с сервером: список и поиск пользователей, смена тарифа/срока/блокировки/роли, сброс сессий, ключи API, журнал, статистика. Ждут базы/оплаты: платежи, промокоды и цены на сервере (пока сохраняются в браузере и сразу используются подпиской и оплатой), удаление аккаунта, возвраты.
  - Лендинг: «Войти» ведёт на `app/#/login`, кнопки тарифов — на оплату, «Бесплатная инструкция» — на `app/#/guide`.

- [x] Тариф Max: без цены — «Скоро», «новые игры и уроки без ограничений»; на лендинге, в подписке и в оформлении оплаты (Max пока не продаётся).
- [x] «Завершить» и время урока — вверху.
- [x] Журнал и ИИ-чат открываются справа, слайд немного уменьшается; на телефоне — лист снизу. Таймер и шумомер — маленькие окна поверх слайда, можно открыть оба сразу и перетащить.

## Сервер и облако (репозиторий `alaqai.back`)

- [x] Отдельный приватный сервер: вход по Google и SMS-коду, сейф ключей (зашифрованы, в браузер не попадают), ИИ и поиск фото через сервер с лимитами тарифа, оплата (CloudPayments; Kaspi по ссылке/QR с подтверждением в админке), промокоды, админка на реальных данных. Установка на VPS в Казахстане одной командой — `deploy/setup.sh`, ночные копии базы.
- [x] Облако учителя (`app/js/data/sync.js`): каждое изменение уходит на сервер, изменения с других устройств приходят сами (раз в 30 секунд и при возврате на вкладку). Работа гостем сохраняется при первом входе. На общем школьном компьютере при входе другого учителя и при выходе данные из браузера убираются. Открытый урок, редактор и формы не перерисовываются от фоновых изменений.
- [x] Ссылка на ДЗ работает на телефоне ученика: список класса и задание приходят с сервера, работа и оценка (для автопроверки) сразу попадают учителю и в журнал.
- [x] Ссылка «только просмотр» на КСП открывается на любом устройстве, у проверяющего ничего не сохраняется, учитель видит, кто смотрел.
- [x] Вход в админку по номеру телефона; «Kaspi: ждут подтверждения» с кнопками «Подтвердить / Отклонить»; страница оплаты сама переходит в кабинет после подтверждения.
- [x] Проверено вместе с настоящим сервером в браузере: ноутбук и телефон одного учителя, ученик без аккаунта, владелец в админке, оплата Kaspi. Скриншоты — `docs/screenshots/platform/srv-*.png`.
